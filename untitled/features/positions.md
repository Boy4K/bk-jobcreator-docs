# Multiple positions

Cloakroom, crafting, selling, boss menu, fridge and printer can each have **several positions**: two cloakrooms, three workbenches, a printer in two offices.

* Click the icon of a point that isn't set: you go in game to place it.
* Click the icon of a point that is set: the list of its positions opens, with **Go**, **Move**, **Delete** (two clicks) and **Add a position**.
* Recipes and items for sale belong to the job, so they work at every position.

## Placing a point in game

A green circle and a wand show where the point goes. Stand on the spot, face the way it should face, then:

| Key                 | Action  |
| ------------------- | ------- |
| `E`                 | confirm |
| `BACKSPACE` / `ESC` | cancel  |

The maximum per point is 10 by default; change it in [Settings](../getting-started/settings.md) (1–50).
