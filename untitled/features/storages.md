# Storages

The archive icon in the job row opens the storages manager. A job can have as many storages as it needs.

| Type             | How it works                                                                |
| ---------------- | --------------------------------------------------------------------------- |
| **Shared**       | one inventory everyone sees: the company storage                            |
| **Personal**     | each employee gets their own private space                                  |
| **Coded locker** | the first code someone types becomes their locker; the boss can look inside |

For each storage: name, who can open it (everyone in the job or from a grade), slots and max weight, and its point in game. **Duplicate** and the arrows help build many quickly.

{% hint style="warning" %}
Changing the type of a storage already in use hides what's inside (it isn't deleted: setting the old type back brings it back). Removing a storage doesn't delete its items, but nobody can open it any more: empty it first.
{% endhint %}

Staff reset a forgotten locker code with `/resetlocker <id> [job]`.
