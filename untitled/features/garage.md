# Garage

The car icon opens the garage manager.

## Points

| Point            | What                                                                                        |
| ---------------- | ------------------------------------------------------------------------------------------- |
| **Attendant**    | the NPC you ask for a vehicle (or an invisible point to target)                             |
| **Vehicle exit** | where and facing which way the vehicle appears                                              |
| **Return**       | where vehicles are brought back (optional: without it, you hand them back to the attendant) |

## Vehicles and options

* Each vehicle has a model, a name in the menu and a **minimum grade**. The panel warns you if a model doesn't exist on the server.
* Plate prefix, livery, fuel on exit, a forced colour, how many vehicles each person can have out, return radius.
* Get in automatically when it comes out; on return, accept only vehicles from this garage.

## Several sites

**Other sites** adds the same garage somewhere else (a second station, a second venue): same vehicles and attendant model, each site with its own attendant, exit and return. A vehicle comes out of the site where you ask for it.
