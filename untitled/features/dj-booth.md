# DJ booth

The music icon opens the DJ booth. It needs **xsound**.

* **Console:** where the DJ opens the music console.
* **Speaker:** where the sound comes from (optional: without it, from the console).
* **More consoles:** for venues with several stages, all controlling the same music.
* **Who can use it:** everyone in the job or from a grade.
* **Sound:** starting range and volume; the DJ can change them from the console within the limits.

Only YouTube links are accepted, so nobody can make players load a random site.
