# Documents

The document icon opens the form editor. Forms are filled in at the job's **printer**.

## Forms

Each form has a title, a heading, fixed text printed on every copy, who can fill it in (everyone or from a grade) and its fields:

| Field type | Example           |
| ---------- | ----------------- |
| Short text | full name         |
| Long text  | description       |
| Number     | fine amount       |
| Date       | date of birth     |
| Choice     | violation type    |
| Yes / No   | vehicle impounded |

**Ready-made forms** adds templates in one click: warrants, citations, reports, permits for police, EMS and gun stores (24 in total). Change them as you like before saving.

## In game

At the printer: pick the form, fill it in, choose how many copies. Each copy is a `documento` item with its own number. Using it opens the sheet; **Show to people nearby** shows it to whoever is close.

A printed document doesn't change if the form is edited or deleted later. Staff can open any document with `/documento <number>`.
